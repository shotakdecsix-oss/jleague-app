# 修正指示：予想最終順位表（全リーグ共通）

シミュレーションの結果を、**予想最終順位表**として全リーグで見られるようにします。
昇降格の区分に依存しないので、J1・J2・J3のどれでも同じように使えます。
（J1で「昇格確率」しか出ていなかった問題も、これで実質的に解消します）

---

## 1. `simulate.py` の出力に追加する

`rankDistribution` は既に持っているので、そこから導けます。**シミュレーションの再実行だけで済み、
モデルの変更は不要です。**

各クラブに次を追加してください。

| キー | 内容 |
|---|---|
| `expectedRank` | 平均順位（小数）。既存 |
| `medianRank` | 中央値の順位（整数） |
| `rankP10` / `rankP90` | 順位分布の10パーセンタイル／90パーセンタイル（整数） |
| `expectedPoints` | 期待勝点（小数）。既存 |
| `projectedRank` | **予想最終順位（整数）**。`expectedRank` の昇順に1から振る |
| `currentRank` | 現在の順位。既存 |
| `rankDelta` | `currentRank - projectedRank`（正なら順位が上がる予想） |

- `teams[]` は **`projectedRank` の昇順**で並べる
- `projectedRank` は**同値を作らない**（`expectedRank` が完全一致することはまず無いが、
  同値なら `expectedPoints` の高い方を上位にする）

**`rankP10` / `rankP90` を必ず入れてください。**「3位」とだけ出すと確定した予想に見えますが、
シーズン序盤の実態は「1位から10位までありうる」です。**幅を出さないと誤解を招きます。**

## 2. 順位タブに「現在 / 予想」の切替を付ける

タブは増やしません。**順位タブの中にサブ切替**（スタッツタブのグループ切替と同じ作り）を置いて、
「現在の順位表」と「予想最終順位」を切り替えます。既定は「現在」。

### 予想最終順位表の列

```
予想順位 ／ クラブ ／ 予想勝点 ／ 予想順位の幅 ／ 現在順位からの増減
   3        湘南      68.4       1〜8位            ↑4
```

- **自クラブの行はハイライト**（`--me-bg`）。クラブ名タップで切替も従来どおり
- `rankDelta` は **↑4 / ↓2 / －** の形。上げ下げを色で分けてよいが、**矢印と数字を必ず併記**すること
  （色だけで示さない）
- 昇格圏・降格圏の色帯は、**現在の順位表と同じ規則**で予想順位にも適用する
  （`promotionRules` にその区分があるリーグのみ）
- 予想勝点は**小数第1位まで**

### 注記（必須）

表の下に、既存の注記規則をそのまま適用してください。

```
※ 第2節終了時点（各クラブ2試合消化）の推定です。10,000回のシミュレーションの平均で、
   幅は上位10%〜下位10%の範囲です。
```

「この確率の出し方」の折りたたみ（ポアソンの説明）は、**この表からも開けるように**してください。
同じ内容を2箇所に書かず、共通の部品として使い回すこと。

## 3. 確認

1. J1・J2・J3のいずれのクラブでも予想最終順位表が出ること
2. `projectedRank` が1から20まで**過不足なく1回ずつ**現れること
3. 全クラブの `expectedPoints` の合計が、**リーグ全体の期待勝点の合計とおおむね一致**すること
   （38節×10試合×（3点または2点）の範囲に収まるか。大きく外れていたらモデル側の不具合です）
4. `rankP10 <= medianRank <= rankP90` が全クラブで成立すること
5. 序盤なので、**多くのクラブで幅が10位以上に広がっているはず**です。幅が極端に狭い場合は
   `rankDistribution` の計算か縮約（`SHRINK_K`）を疑ってください
