# 実装指示：第5弾 改訂3（配色の確定）

改訂2の「2. 背景をもっとクラブカラーに寄せる」を**破棄し、この章で置き換えます。**
混色比を上げる方式はやめ、**クラブカラーをベタで敷きます。**

`data/masters/*.json` は更新済みです（`color` / `colorSub` を差し替え）。**マスタ側の作業は不要です。**

---

## 1. 色の役割（この4つだけ）

| 場所 | 色 |
|---|---|
| ヘッダー | `color`（1stカラー）**ベタ塗り** |
| タブバー | `colorSub`（2ndカラー）**ベタ塗り** |
| ボディ背景 | `color`（1stカラー）**ベタ塗り** |
| カードの枠線 | `colorSub`（2ndカラー）2px |

**グラデーションは使いません。** ヘッダーとボディが同じ1stカラーのベタ、その間にタブバーが2ndカラーの帯として入る、
という構成です。カードは白のまま、2ndカラーの枠で締めます。

```css
body   { background: var(--color); }
header { background: var(--color); }
.tabbar{ background: var(--color-sub); }
.card  { background:#fff; border:2px solid var(--color-sub); border-radius:14px;
         box-shadow:0 2px 8px rgba(0,0,0,.10); }
```

## 2. 文字色は輝度で自動反転させる（**必須**）

1stカラーは真っ黄色（柏レイソル `#fff100`）から濃紺（FC東京 `#11216c`）まで幅があります。
**既存の `luminance()` をそのまま使い、0.5 を境に文字色を反転**させてください。

```js
const ink = luminance(color) > 0.5 ? "#111111" : "#ffffff";
```

この `ink` を、**背景の上に直接載るテキスト全てに適用**します。

- ヘッダーのタイトル
- **セクション見出し（「次の試合」など）** ← 現状 `var(--sub)` のグレーのままだと、濃紺のクラブで完全に読めなくなります
- フッターの「データ取得: …」

タブバーの文字色も同様に `colorSub` の輝度で判定してください（1stとは別に計算すること）。

**カードの中は従来どおりの文字色のまま。** カードは白なので反転させません。

### 特に確認してほしい6クラブ

1stカラーが明るく、**白文字が乗らない**クラブです。この6つで文字が黒に反転していることを必ず確認してください。

```
柏レイソル              #fff100
ジェフユナイテッド千葉  #ffe100
ベガルタ仙台            #fcc800
栃木SC                  #fff100
ギラヴァンツ北九州      #fff100
FC大阪                  #7fcaf1
```

## 3. マスタの色について（更新済み・作業不要）

- **1stカラーはWeb調査した実際のクラブカラー**に差し替えました（出典は各マスタの `meta.colorNote`）。
  これまでの手入力の推測値ではありません
- **2ndカラーは1stカラーから機械生成**しています。**明るい1stカラーは暗く（0.58倍）、暗い1stカラーは明るく（白へ35%寄せ）** 変換しており、
  ヘッダーとタブバーが必ず見分けられる濃さの差が出るようにしてあります
- レイラック滋賀FC だけは調査した一覧表に載っていなかったため、Wikipediaの「ブルーとパープル」から
  `#7b62b5` を仮に設定しています。**この1クラブだけ要確認**です
- 湘南の青、名古屋の黄のような**実際の2ndカラーを使いたいクラブがあれば、マスタの `colorSub` を直接
  書き換えて構いません。**表示専用の値で、計算には一切使っていません

## 4. 動作確認

設計側で先に試作して確認済みです。以下が確認できていれば同じ状態です。

1. **湘南（黄緑 `#82c039`）／柏レイソル（黄 `#fff100`）／FC東京（濃紺 `#11216c`）** の3クラブで表示する
2. どのクラブでも、**背景の上のセクション見出しが読めること**（濃紺で白、黄で黒）
3. どのクラブでも、**カード内の順位表の数字が従来どおり読めること**
4. カードの枠線が2ndカラーで、背景から浮いて見えること
5. `<meta name="theme-color">` も1stカラーに追随すること（スマホのアドレスバーが同じ色になります）
