`add-projected-table.md` の **「2. 順位タブに『現在 / 予想』の切替を付ける」を破棄します。**
順位タブに予想順位表は作りません。

代わりに、**ホームタブのシミュレーション欄に、選択中のクラブの「最もあり得る順位」を1つだけ出します。**

`simulate.py` の出力追加（1章）はそのまま有効です。**1つだけ足してください。**

---

## 1. `simulate.py` に `modeRank` を追加

**「最もあり得る順位」＝ `rankDistribution` の最頻値**（確率が最大の順位）です。平均順位ではありません。

| キー | 内容 |
|---|---|
| `modeRank` | `rankDistribution` が最大値をとる順位（整数） |
| `modeRankProb` | **その順位になる確率**（`rankDistribution[modeRank - 1]`） |

- 最大値が複数の順位で同値のときは、**`expectedRank` に近いほうを選ぶ**
- 1章で足した `expectedRank` / `medianRank` / `rankP10` / `rankP90` / `expectedPoints` はそのまま出力に残す
  （画面では使わないものもありますが、あとで効きます）
- **`projectedRank`（全クラブに1〜20を振り直す値）は不要になったので削って構いません**

## 2. ホームタブでの見せ方

昇格確率などのタイルと同じブロックに、**予想順位を1つ**置きます。

```
        予想順位
          3位
   その確率 9.2% ／ 1〜8位に入る可能性が高い
```

- 順位を**一番大きく**出す（確率タイルと同じ字の大きさで揃える）
- **`modeRankProb` を必ず併記すること。** ここが今回いちばん重要です。
  シーズン序盤は分布が平坦で、最頻値でも確率は10%前後しかありません。**順位だけ大きく出すと
  「3位で決まり」に見えます**が、実際は「20通りのうち3位がいちばん多いだけ」です。
  確率を添えることで、その頼りなさがそのまま伝わります
- 補助として `rankP10`〜`rankP90` の幅を小さく添える
- **`modeRankProb` が20%未満のときは、順位の下に「まだ大きく動きます」と一言添える**
- 既存の「※ 第2節終了時点（各クラブ2試合消化）の推定です」の注記と、
  「この確率の出し方」の折りたたみは、このブロックの下にまとめる（今のままで可）

## 3. 確認

1. J1・J2・J3のどのクラブでも予想順位が出ること
2. `modeRank` が `rankDistribution` の最大値の位置と一致すること（10クラブほど手で突き合わせる）
3. `rankP10 <= modeRank <= rankP90` がおおむね成立すること
   （分布が偏っていると外れることはありますが、大きく外れるなら計算を疑ってください）
4. 序盤なので **`modeRankProb` はどのクラブも10%前後のはず**です。50%を超えるクラブが出たら、
   縮約（`SHRINK_K`）が効いていないか、`rankDistribution` の正規化を疑ってください
