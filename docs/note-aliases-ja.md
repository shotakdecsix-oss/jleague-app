## 採用・除外の基準

カタカナ愛称は原則すべて採用しました。地名は、次のいずれかに当たるものを**意図的に除外**しています。

| 除外した語 | 理由 |
|---|---|
| 大阪 / 東京 / 横浜 / 栃木 | 複数クラブで曖昧 |
| 町田 / 山口 / 清水 / 松本 / 秋田 / 宮崎 / 富山 / 長野 / 岡山 / 福島 | **選手や解説者の姓と一致する**（町田浩樹、山口蛍、秋田豊など） |
| 柏 | 1文字。「柏木」などの姓に部分一致する |
| 千葉 / 神戸 / 川崎 | 地名として頻出、または女子クラブ・他競技クラブと混同 |

除外理由は各マスタの `meta.aliasesJaExcluded` にも残してあります。**別名を足すときは、その語が他クラブや
人名に部分一致しないか必ず確認してください。**

## **重要：1件だけ部分一致の衝突があります**

全60クラブの正式名と別名を総当たりで突き合わせたところ、完全一致の重複はゼロでしたが、
**部分一致が1件**見つかりました。

```
「C大阪」（セレッソ大阪）が「FC大阪」（FC大阪）に部分一致する
```

FC大阪の記事が、単純な部分一致だとセレッソ大阪に振り分けられます。**「C大阪」はメディアが日常的に使う
表記なので外したくありません。**代わりに、照合ロジックをこうしてください。

> **長い語から順に照合し、マッチした部分を文字列から取り除いてから、次の語を照合する。**

「FC大阪」が先に消費されるため「C大阪」は残った文字列に現れず、正しく振り分けられます。
この規則は「栃木SC」と「栃木シティ」のような他の紛らわしい組み合わせにも同時に効きます。

**テストに次の2ケースを必ず入れてください。**

- 「FC大阪が勝利」→ FC大阪のみ（セレッソ大阪に入らないこと）
- 「C大阪とFC大阪が対戦」→ 両方に入ること
